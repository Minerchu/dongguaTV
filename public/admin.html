PanSou 网盘搜索

接入 fish2018/pansou 后，用户搜索影视时也会同时返回夸克、百度、阿里、UC 等网盘资源。 本项目不内置网盘资源。使用 docker-compose 部署时已自动带上 PanSou 服务；也可以直接填你已有的 PanSou 地址。

{{ pansouResult.success ? ('连接正常，延迟 ' + pansouResult.latency + 'ms，插件 ' + (pansouResult.plugins || 0) + ' 个') : (pansouResult.error || '连接失败') }}
一键部署 PanSou（推荐）

在任意一台能访问 Telegram 的服务器 / NAS 上执行：

docker run -d --name pansou -p 8888:8888 ghcr.io/fish2018/pansou:latest

部署完成后，在上面填 http://服务器IP:8888，点「测试连接」→「保存配置」。 如果 PanSou 开启了认证，再用 AUTH_USERS 的账号登录拿到 Token 填入。

#EXTM3U
#EXTINF:-1 tvg-id="cctv1" tvg-logo="https://example.com/cctv1.png" group-title="央视",CCTV-1

如何找到并添加采集站
先搞清楚要填什么

本项目的采集站必须是 Maccms V10 的 JSON 接口，不是网站首页，也不是播放页。 常见形式如下（末尾有没有斜杠都行）： 

https://api.example.com/api.php/provide/vod
https://example.com/inc/apijson.php
用谷歌搜索采集站

在 Google 里搜索下面任意一个关键词组合，能找到很多公开的采集接口：

  • "api.php/provide/vod"
  • inurl:"api.php/provide/vod"
  • maccms 采集接口
  • "inc/apijson.php"

也可以搜「影视采集站 分享」「Maccms 资源站 接口」等中文关键词。

验证接口是不是真的能用

把地址复制到浏览器，后面加上 ?ac=list&pg=1：

https://api.example.com/api.php/provide/vod?ac=list&pg=1

如果看到类似下面的 JSON，说明格式正确：

{
  "code": 1,
  "msg": "数据列表",
  "list": [
    { "vod_id": 123, "vod_name": "示例电影", "vod_pic": "https://..." }
  ]
}
看到一整页网页、XML、或者 404/500，都说明不是可用的 JSON 采集接口，换一个。
添加或批量导入

单个接口可以在「采集站管理」填写名称和地址，点 测试并添加。 手里已经有 TVBox 配置或一堆接口时，打开 「导入采集源」 更快：

  • TVBox 配置：每行粘贴一个配置地址，支持明文、Base64、图片隐写、2423/2324 加密和 urls 仓库。
  • 苹果CMS 接口：每行一个，写成 名称,https://example.com/api.php/provide/vod 或只填地址。
  • 点 解析并查重 先看结果。已存在的接口会标灰，新接口勾选后再导入。
TVBox 里的 csp_ 内置源、Jar 源需要播放器自己运行，网页后台无法直接使用，导入时会自动跳过并写明原因。
常见问题
测试超时接口服务器慢或被墙，换个站；也可以调大环境变量 TEST_TIMEOUT。
返回 HTML / XML不是 JSON 接口，或者地址少了 /api.php/provide/vod 这一段。
接口能用但搜不到片该站资源少，属于正常情况；多添加几个站即可互补。
搜索很慢减少启用站点数，或把慢站关掉；搜索默认 6 秒超时。
添加后前台搜不到确认该行是「启用」状态；刚添加的站点可能需要等它自己缓存更新，换个关键词再试。
网盘搜索

在「网盘搜索」页填 PanSou 地址即可。用户搜索时会多出一个「网盘资源」标签页， 显示夸克 / 百度 / 阿里 / UC 等分享链接和提取码。

播放直连与线路切换

前台和安卓客户端会直接连接采集站的播放地址，视频与 m3u8 分片不经过本站服务器中转。 用户和源站之间的线路越好，播放越顺畅。

当前线路播放失败时只提示手动切换，不会自动换源。 如果提示跨域错误或 m3u8 无法加载，通常是源站限制，换其他线路即可。

播放器可单独调用：/player/?url=你的m3u8地址&name=影片名。

PING 巡检

服务每 10 分钟对启用的采集站做一次 HTTP PING。连续失败 3 次的站点会临时冷却 5 分钟，之后自动重新参与搜索； 不会永久关闭。后台「采集站管理」会显示延迟、成功率和冷却剩余时间，也可以点「PING 巡检」立即检查。 PING 只代表站点能连通，不保证接口一定返回可播放的 m3u8。

备份与恢复

后台「备份与恢复」可以下载当前配置、立即备份、恢复历史备份，或上传之前下载的 JSON。 服务每天自动备份一次，保留最近 7 份，文件在 data/backups/。
