一键部署 PanSou（推荐）

在任意一台能访问 Telegram 的服务器 / NAS 上执行：

docker run -d --name pansou -p 8888:8888 ghcr.io/fish2018/pansou:latest

部署完成后，在上面填 http://服务器IP:8888，点「测试连接」→「保存配置」。 如果 PanSou 开启了认证，再用 AUTH_USERS 的账号登录拿到 Token 填入。

你还没有添加采集站。建议先到「采集站管理」添加至少一个 Maccms 接口，否则客户端搜索为空。

签名与更新

APK 使用本站自动生成并保存在 data/android-client 的签名。重新生成时保持同一份数据目录，才能覆盖安装更新。

如果通过反向代理部署，请在地址中填写代理后的域名，例如 https://tv.example.com，不要填容器内部地址。

如何找到并添加采集站
先搞清楚要填什么

本项目的采集站必须是 Maccms V10 的 JSON 接口，不是网站首页，也不是播放页。 常见形式如下（末尾有没有斜杠都行）： 

https://api.example.com/api.php/provide/vod
https://example.com/inc/apijson.php
用谷歌搜索采集站

在 Google 里搜索下面任意一个关键词组合，能找到很多公开的采集接口：

  • "api.php/provide/vod"
  • inurl:"api.php/provide/vod"
  • maccms 采集接口
  • "inc/apijson.php"

也可以搜「影视采集站 分享」「Maccms 资源站 接口」等中文关键词。

验证接口是不是真的能用

把地址复制到浏览器，后面加上 ?ac=list&pg=1：

https://api.example.com/api.php/provide/vod?ac=list&pg=1

如果看到类似下面的 JSON，说明格式正确：

{
  "code": 1,
  "msg": "数据列表",
  "list": [
    { "vod_id": 123, "vod_name": "示例电影", "vod_pic": "https://..." }
  ]
}
看到一整页网页、XML、或者 404/500，都说明不是可用的 JSON 采集接口，换一个。
填进后台并测试

回到「采集站管理」，填站点名称和 API 地址，点 测试并添加。 显示「连接正常」就代表添加成功，前台搜索会立刻用上。

常见问题
测试超时接口服务器慢或被墙，换个站；也可以调大环境变量 TEST_TIMEOUT。
返回 HTML / XML不是 JSON 接口，或者地址少了 /api.php/provide/vod 这一段。
接口能用但搜不到片该站资源少，属于正常情况；多添加几个站即可互补。
搜索很慢减少启用站点数，或把慢站关掉；搜索默认 6 秒超时。
添加后前台搜不到确认该行是「启用」状态；刚添加的站点可能需要等它自己缓存更新，换个关键词再试。
网盘搜索

在「网盘搜索」页填 PanSou 地址即可。用户搜索时会多出一个「网盘资源」标签页， 显示夸克 / 百度 / 阿里 / UC 等分享链接和提取码。
